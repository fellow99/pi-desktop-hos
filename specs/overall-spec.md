# overall-spec.md — pi-desktop-hos 整体规格

> 本文件是 **Pi Desktop · Electron on HarmonyOS 版** 的系统级规格（技术无关）。
> 版本：`0.12.1` / `1201`；上游 `pi` v1.2.0 + `pi-web` v0.12.1。最后更新：2026-10-31。
> 需求编号：`FR-HOS-*`；动作词：MUST / MUST NOT / SHOULD / MAY。

---

## 1. 目的与用户

把 Pi / Pi Web 封装为鸿蒙 PC / 平板上的桌面应用：用户安装 HAP 后直接获得完整 agent 对话、
工具、会话与扩展；不需要命令行、浏览器或手动起服务。

目标用户：鸿蒙 PC / 平板用户；需要本地数据、可控模型 Provider、桌面级能力（窗口/托盘/通知）的用户。

---

## 2. 用户故事

- 作为用户，我安装 HAP 后打开就能对话，不需要配置服务。
- 作为用户，我的会话、模型、设置保存在本机，重启后恢复。
- 作为用户，我能让 agent 读写文件、执行命令、搜索代码、使用 Git。
- 作为用户，我能选择工作区、收到通知、把外链交给系统浏览器。
- 作为维护者，我能用固定上游 + 五阶段流水线复现签名 HAP。
- 作为审核者，我能从真机记录与能力清单验证每条能力。

---

## 3. 功能需求

### 3.1 启动

- **FR-HOS-001**（MUST）：应用启动后自动准备运行时与本地服务，用户无需手动操作。
- **FR-HOS-002**（MUST）：启动阶段可见；失败显示错误页 + 日志入口。
- **FR-HOS-003**（MUST）：单实例 + 随机端口；端口回报给壳。
- **FR-HOS-004**（MUST）：首启解压载荷；二次启动 SHA-256 marker 幂等。
- **FR-HOS-005**（MUST）：退出优雅关闭服务；超时兜底。

### 3.2 对话与模型

- **FR-HOS-006**（MUST）：创建会话、流式回复、中断/重载。
- **FR-HOS-007**（MUST）：配置 Provider / API Key / 默认模型。
- **FR-HOS-008**（MUST）：会话持久化与恢复。
- **FR-HOS-009**（MUST）：会话导出可用，或给出明确原因（补丁 0002）。
- **FR-HOS-010**（SHOULD）：图片附件与视觉识图。

### 3.3 工具

- **FR-HOS-011**（MUST）：读写文件、列目录、搜索、执行命令。
- **FR-HOS-012**（MUST）：无系统 `bash`/`find`/`grep` 时用纯 JS 扩展同名顶替。
- **FR-HOS-013**（MUST）：工具失败返回结构化错误，不伪造成功。
- **FR-HOS-014**（SHOULD）：Git 工具组（纯 JS，无系统 git）。
- **FR-HOS-015**（SHOULD）：MCP HTTP/SSE；stdio 按能力。
- **FR-HOS-016**（MUST）：项目信任门禁默认 `ask`。

### 3.4 文件与工作区

- **FR-HOS-017**（MUST）：可选工作区；四主目录（沙箱/桌面/文档/下载）。
- **FR-HOS-018**（MUST）：浏览围栏，只能向下。
- **FR-HOS-019**（MUST）：需要授权的目录必须请求权限；未授权时给出明确引导。
- **FR-HOS-020**（SHOULD）：主目录记忆。

### 3.5 平台能力

- **FR-HOS-021**（MUST）：外链走系统浏览器/外链中转页。
- **FR-HOS-022**（MUST）：通知能力不可用时如实说明（当前系统设置关闭）。
- **FR-HOS-023**（MUST）：窗口状态记忆、F11 全屏、返回键处理。
- **FR-HOS-024**（MUST）：后台长任务保持（taskKeeping）。
- **FR-HOS-025**（MUST）：PTY 不支持时显式 `unsupported`。

### 3.6 品牌与版本

- **FR-HOS-026**（MUST）：品牌名 `Pi Desktop`；用户可见 `Pi Web` 清零。
- **FR-HOS-027**（MUST）：图标/Logo 来自父工程 `assets/`。
- **FR-HOS-028**（MUST）：技术标识符不变；版本检测关闭但保留当前版本显示。
- **FR-HOS-029**（MUST）：版本 `0.12.1` / `1201`；发布 tag `v0.12.1`。

### 3.7 构建与证据

- **FR-HOS-030**（MUST）：五阶段流水线可复现；`smoke-node22` 0 FAIL。
- **FR-HOS-031**（MUST）：补丁 2 条，幂等可逆。
- **FR-HOS-032**（MUST）：HAP 可签名安装；真机验证记录可追溯。
- **FR-HOS-033**（MUST）：构建/发布失败显式失败，不产出半成品。
- **FR-HOS-034**（MUST）：签名材料/API Key 不入库。

## 5. 非功能需求

- **性能**：首屏与启动可接受；解压流式低内存。
- **安全**：随机密码 + Cookie；密码不入日志；生产无调试入口；最小权限。
- **可靠**：失败可见；崩溃留痕；单实例。
- **兼容**：API 17 兼容 / 24 目标；真机 API 26 已验。
- **可维护**：零上游改动；补丁可逆；版本/运行时锁定。
- **合规**：权限声明有调用点；无浏览器语义；AI 生成标识。

## 6. 边界

**在范围内**：HAP 装配、Electron 集成、鉴权、窗口、能力桥、扩展、品牌、构建、真机验证。

**不在范围内**：修改上游；自建模型/账号/云同步；应用商店材料提交；官网；PTY 原生件开发。
