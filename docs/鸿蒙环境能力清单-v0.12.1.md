## C. 关键结论与依据

### C.1 根因分层模型（L1–L4）

> 本轮**逐层复核**：分层模型本身不变，只有 **#17 的归因强度**与 **#16 的 L1 面**有实质变化。

| 层 | 性质 | 可恢复性 | 本工程涉及项（本轮实测） |
|---|---|---|---|
| **L1** 平台硬约束 | SELinux / seccomp / 内核 ABI / OS 授权门 | **不可恢复**（只能绕） | #11 符号链接（应用域）、#14 用户目录写、#15 的「`exit`/`close` 永不送达」、#16 的 L1 面（**仍未证伪**）、#17 子进程 Node（**终止原因已取得：`Signal 31` / core dumped**）、#31 开机自启（仅旁证） |
| **L2** 原生产物缺失 | 缺某架构的 `.node` / 外部二进制 | **可恢复**（交叉编译或内置替代） | #3 SWC（已解，内置 WASM）、#16 PTY（**已证**的阻断点：缺 `prebuilds/openharmony-arm64/pty.node`）、#18 `fd` / #19 `rg`（**已解**：随包纯 JS 扩展同名顶替） |

| **L4** 上游接口缺失 | pi / pi-web 没有该能力或该工具 | 需上游改动或壳扩展 | #32 文件围栏（`bash` 不可围）、`bash` 工具的超时语义（已由壳扩展接管）、#28 的「适配器对缺失函数不报错」面 |

### C.4 安全与「陷阱」清单（本轮实测复现的）

1. **裸名探测 `/system/bin` 的危险模式仍在**（本轮**有意规避**，未复现 `reboot` → `begetctl` 回弹）：`/system/bin` 里有悬空软链与指向非 toybox 的软链；**只对 `toybox <n>` 传参**，且 `<n>` 必须先确认在裸 `toybox` 的小程序表内。
2. **`command -v` 不可作为「可执行/在哪」的判据**：`command -v cat` → `alias cat=cat`，`which cat` → `/bin/cat`（两个答案不同）；要判名字归属须 `unalias -a` 后 `type`（本轮 11 个遮蔽名即由此确认）。
3. **跨域可见性（含 ENOENT 伪装）**：同路径在 `sh` 域与 `debug_hap` 域结论不同，不可见时可报 `ENOENT` 而非 `EACCES`（#25 复现）。
4. **`snapshot_display` 不能判白屏**（沿用）；本轮补充：**`uitest dumpLayout` 可读到 Web 内容的无障碍文本**（`Pi Desktop，版本：web 0.12.1，pi 1.2.0`、`Select model`、`0 个变更文件`、`README.md`），
   是「不截图也能取 UI 文本」的可用通道（`T10-6-shell.txt`）。⚠️ 但其可见范围受**渲染状态**限制：本轮弹窗探针把主窗口导到 401 页时，layout 里出现的是 `Authentication required` + `← 返回 Pi Desktop`（`T10-6-shell.txt`），
   复位到首页后这两条消失 —— 即 **dumpLayout 反映的是「当前渲染出来的东西」**，不能用来断言「某功能没实现」。
5. **`hdc fport` 生命周期与残留**：映射随发起它的 `hdc` 客户端退出即失效，且**残留映射会让新映射失败**（`TCP Port listen failed at <port>`）。
   → 「建转发 + 消费 + 拆除」必须**在同一条命令内**完成；本轮每次先 `fport rm tcp:19229`（反复出现 `[Fail]Remove forward ruler failed, ruler is not exist` 属正常噪声）。

| 观测 | 本轮结果（证据：`T10-2-spawn-node-mcp.txt`、`T10-12-npm-path.txt`） |

### D.2 平台事实（本轮核实）

1. 应用进程 uid/gid **`20020218`**（v0.11.1 为 `20020215` —— **进程 uid 变了**），SELinux 域 `u:r:debug_hap:s0`（debug 构建；release 签名包不可侧载）。
2. 应用进程拓扑：主进程 + Renderer + GPU + NetworkService（Chromium 多进程），全部同一 uid；`--no-sandbox --no-zygote --ozone-platform=ohos`。
3. 应用沙箱根 `/data/storage/el2/base/files` 为 **`hmfs`**（`/proc/mounts` 实证）；`/storage/Users` 为 **`tmpfs`**；用户目录 `hmdfs` 挂载点在 `/data/storage/el2/{share,distributedfiles}`。
   三者的 `chmod` / 硬链接 / symlink 语义**不同**（见 §C.2）。
4. **shell 域对同一路径可能报 `ENOENT` 而非 `EACCES`**（`/data/service/hnp`），而应用域 `statSync` 正常 → 「shell 域看不到」**不等于**「不存在」。
5. shell 域：`ln -s` **成功**、硬链接 `ln` **被拒**（`Permission denied`）、`chmod 640` **如实生效**（`-rw-r-----`）—— 与 v0.11.1 相比仅 symlink 一项**变了**。
6. shell 域对 `/system/bin` **单条目** `lstat` 被拒（`ls -l /system/bin/cat` → `Permission denied`、`[ -L ]` 恒假），**目录列表可读**、`readlink` 可读 → 枚举必须走目录列表。
7. `uname -a` 尾部 `Toybox` 是内核 utsname 字段，不是 shell 身份；权威判据是 `KSH_VERSION`。
8. 服务端监听 `0.0.0.0:<随机端口>`（本轮 **40529** / **34255**），渲染层经**局域网 IP** 访问（`PI_WEB_HOSTNAME=192.168.137.31`）；`NO_PROXY` 含 `127.0.0.1,localhost,192.168.137.31`。
9. `PI_WEB_PASSWORD` 每启随机（43 字符，**从不回显**）；Basic 用户名固定 `pi`（`pi-web/lib/web-auth.ts`）。
10. `PI_OFFLINE=1`、`PI_WEB_SKIP_VERSION_CHECK=1` 默认开启 → pi 永不尝试下载外部二进制/包；首页版本检查被禁用（#20 / #30 的直接原因）。
11. 设备重启后应用**不自启**（**v0.11.1 观测**；本轮未重启，仅旁证：无自启声明字段）；**锁屏会阻断 `aa start`**（密码锁下无法自动解锁）。
12. `/data/local/tmp` 在设备重启后**仍持久**（沿用），且 shell 域可**建文件 / 建软链 / chmod**。
13. `uitest uiInput`（`keyEvent` / `swipe` / `text` / `dumpLayout` / `screenCap`）在 shell 域可用；本轮 `uitest dumpLayout -p <file>` 成功（292 KB JSON，可读 Web 无障碍文本）→ 是**UI 文本取证**的可用通道；`text` 只能在已聚焦处输入、**无法输入密码锁屏**。
14. `snapshot_display` 可出图但拍不到 GPU 合成面（沿用）；`dumpLayout` 是更优判据（本轮再次证实，见 §C.4 #4 的边界）。
15. Node 运行时 `22.17.0`（Electron 37 内置）；**CDP 默认执行上下文没有 `require`/`module`/`exports`**，入口是 `process.mainModule.require(...)`（`process.getBuiltinModule` 亦可）。
16. HAP `pack.info` 报 `apiVersion compatible 17 / target 24`，设备 API **26** —— 二者不矛盾（声明 vs 设备能力）。
17. **ABI 编号双口径**：运行时归档标签 `libelectron_138.tar.gz`（工程口径「ABI 138」）vs 进程内 `process.versions.modules = 136`；本工程**不**依赖该编号做运行时断言。
18. HNP 侧无 `git`；`npm`/`npx` 存在但需要 node 执行 JS → 受 #17 限制不可用（**新增事实**）。
19. 硬件 I²C / 内核模块类 toybox 小程序属系统级，本轮**未使用**（沿用）。
